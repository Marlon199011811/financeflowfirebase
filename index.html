📖 Como Configurar o Firebase

1
Criar Projeto

Acesse console.firebase.google.com, crie um projeto e adicione um App Web.

2
Authentication

Em Build → Authentication → Sign-in method, ative Email/Password.

3
Firestore Database

Em Build → Firestore Database, crie o banco no modo de produção.

4
Regras de Segurança

Cole as regras abaixo no Firestore para proteger os dados de cada usuário.

5
Credenciais

Em Project Settings → Seus aplicativos, copie o firebaseConfig e cole na tela de configuração do app.

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { // Perfil do usuário — cada um acessa só o seu match /usuarios/{userId} { allow read, write: if request.auth != null && request.auth.uid == userId; } // Lançamentos financeiros — isolados por usuário match /users/{userId}/lancamentos/{doc} { allow read, write: if request.auth != null && request.auth.uid == userId; } } }
